# Блокнот конспектов
 
Всё для учёбы в одной папке: конспекты в Markdown, списки дел, PDF, презентации и ссылки на артефакты Claude. А рядом с каждым файлом есть чат с Claude, который этот файл уже прочитал. Можно спросить, что непонятно, или попросить объяснить проще, ничего не копируя и не пересказывая.
 
**[⬇ Скачать последнюю версию](https://github.com/trashIisland/study-notebook-releases/releases/latest)**
 
Работает на Windows 10 и 11, на Mac с macOS 11 и новее (подходят и M-чипы, и Intel) и на Linux: Ubuntu 22.04+, Debian 12+ и других дистрибутивах.
 
## Как установить
 
Все файлы лежат в **[Releases](https://github.com/trashIisland/study-notebook-releases/releases/latest)**. Аккаунт на GitHub не нужен, просто скачайте файл для своей системы.
 
### Windows
 
Скачайте `StudyNotebook-Setup-<версия>.exe` и запустите его.
 
Скорее всего, Windows насторожится и покажет синее окно SmartScreen. Так бывает, потому что у приложения нет сертификата цифровой подписи. Нажмите **«Подробнее»**, затем **«Выполнить в любом случае»**.
 
Дальше всё просто: в установщике одна страница. Решите, нужен ли ярлык на рабочем столе, и нажмите «Установить», потом «Готово». Если оставить галочку «Запустить», приложение откроется сразу.
 
Права администратора не понадобятся: приложение ставится только для вашей учётной записи (в `%LOCALAPPDATA%\Programs`). В меню «Пуск» оно появится в любом случае.
 
### macOS
 
Сначала узнайте, какой у вас Mac: меню  → «Об этом Mac», строка «Чип» или «Процессор».
 
- **M1–M4** (Apple Silicon): скачайте `.dmg` с пометкой **`arm64`**
- **Intel**: скачайте `.dmg` с пометкой **`x64`**
Откройте `.dmg` и перетащите «Блокнот конспектов» в «Программы».
 
При первом запуске macOS, скорее всего, заупрямится. Она скажет, что не может проверить разработчика, а иногда даже что приложение «повреждено». Пугаться не нужно: так macOS реагирует на всё, что не подписано сертификатом Apple. Откройте **Системные настройки → Конфиденциальность и безопасность**, промотайте вниз до строки «Блокнот конспектов был заблокирован» и нажмите **«Всё равно открыть»**.
 
Если такой кнопки нет, поможет одна команда в Терминале:
 
```bash
xattr -dr com.apple.quarantine "/Applications/Блокнот конспектов.app"
```
 
Это нужно сделать всего один раз. Потом приложение будет открываться как обычно.
 
### Linux (Ubuntu, Debian)
 
Скачайте `study-notebook_<версия>_amd64.deb` и установите двойным кликом через Центр приложений. Или в терминале:
 
```bash
sudo apt install ./study-notebook_<версия>_amd64.deb
```
 
После установки приложение появится в меню.
 
Ключ Claude хранится в системной связке ключей (GNOME Keyring или KWallet). В Ubuntu она есть из коробки. Если у вас её нет, приложение предупредит об этом в настройках. Тогда ключ будет храниться только до закрытия приложения.
 
**Другой дистрибутив?** Возьмите `StudyNotebook-<версия>.AppImage`, сделайте файл исполняемым и запустите:
 
```bash
chmod +x StudyNotebook-*.AppImage
./StudyNotebook-*.AppImage
```
 
Для AppImage нужен FUSE 2: на Ubuntu 24.04 это пакет `libfuse2t64`, на 22.04 это `libfuse2`. И одна оговорка: на Ubuntu 24.04 и новее AppImage на Electron не запускается из-за ограничений AppArmor. Там лучше сразу ставить `.deb`.
 
## Первые шаги
 
Пара минут настройки, и можно садиться за учёбу.
 
1. **Выберите папку для конспектов.** Внутри будут обычные `.md`-файлы без какой-либо привязки к приложению. Их откроет любой редактор.
2. **Подключите Claude.** Откройте настройки (`Ctrl+,`, на Mac `⌘,`) и вставьте ключ Claude API. Получить его можно на [console.anthropic.com](https://console.anthropic.com/) в разделе API Keys. На счёте должен быть положительный баланс. Ключ хранится в зашифрованном виде и только на вашем компьютере.
3. **Укажите баланс.** В разделе «Траты» нажмите на карандаш и впишите, сколько сейчас денег на счёте Anthropic. Дальше приложение само вычитает стоимость каждого запроса, и вы всегда видите, сколько осталось.
## Обновления
 
Об этом можно не думать: приложение само проверяет новые версии при запуске и каждые 4 часа.
 
- **Windows и Linux.** Обновление тихо скачивается в фоне, а в шапке появляется кнопка **«Перезапустить»**. Если не хотите прерываться, просто не нажимайте её: обновление установится, когда вы закроете приложение. Для `.deb` система попросит пароль.
- **macOS.** В шапке появится **«Вышла версия … — Скачать»**. Кнопка откроет страницу новой версии. Скачайте свежий `.dmg` и замените им приложение в «Программах». К сожалению, неподписанным приложениям macOS не разрешает обновляться самостоятельно.
Ваши конспекты, чаты и настройки при обновлении сохраняются. Проверить обновления вручную или посмотреть все версии можно в **Настройки → Обновления**.
