# Блокнот конспектов

Десктопный блокнот для учёбы: Markdown-конспекты, списки дел, PDF, презентации и ссылки на артефакты Claude в одной папке, а рядом с каждым файлом — чат с Claude, который видит его текст.

Здесь только готовые сборки — **[скачать последнюю версию](https://github.com/trashIisland/study-notebook-releases/releases/latest)**.

Работает на Windows 10/11 (x64), macOS 11+ (Apple Silicon и Intel) и Linux x64 (Ubuntu 22.04+, Debian 12+ и другие).

## Установка

Файлы — в разделе **[Releases](https://github.com/trashIisland/study-notebook-releases/releases/latest)**. Аккаунт GitHub не нужен.

### Windows

1. Скачайте `StudyNotebook-Setup-<версия>.exe` и запустите.
2. Приложение не подписано сертификатом, поэтому Windows может показать синее окно SmartScreen: «Подробнее» → «Выполнить в любом случае».
3. В установщике одна страница: оставьте или снимите галочку **«Создать ярлык на рабочем столе»** → «Установить» → «Готово» (с галочкой «Запустить» приложение сразу откроется).

Ставится только для вашей учётной записи (в `%LOCALAPPDATA%\Programs`), права администратора не нужны. В меню «Пуск» приложение появится в любом случае.

### macOS

1. Скачайте `.dmg` под свой Mac: **`arm64`** — Apple Silicon (M1–M4), **`x64`** — Intel. Какой у вас: меню  → «Об этом Mac» → «Чип» или «Процессор».
2. Откройте `.dmg` и перетащите «Блокнот конспектов» в «Программы».
3. Первый запуск: приложение не подписано сертификатом Apple, поэтому macOS его остановит («не удаётся проверить разработчика» или «повреждено»). Откройте **Системные настройки → Конфиденциальность и безопасность**, внизу — «Блокнот конспектов был заблокирован» → **«Всё равно открыть»**. Если такой кнопки нет, в Терминале:
   ```bash
   xattr -dr com.apple.quarantine "/Applications/Блокнот конспектов.app"
   ```
   Это нужно сделать один раз.

### Linux (Ubuntu, Debian)

1. Скачайте `study-notebook_<версия>_amd64.deb`.
2. Установите двойным кликом (Центр приложений) или в терминале:
   ```bash
   sudo apt install ./study-notebook_<версия>_amd64.deb
   ```
3. Приложение появится в меню приложений.

Ключ Claude хранится в связке ключей (GNOME Keyring или KWallet) — в Ubuntu она есть сразу. Если её нет, приложение предупредит в настройках: ключ будет жить только до закрытия.

**Другие дистрибутивы** — `StudyNotebook-<версия>.AppImage`: `chmod +x StudyNotebook-*.AppImage` и запустить. Нужен FUSE 2 (`sudo apt install libfuse2t64` на Ubuntu 24.04, `libfuse2` — на 22.04). На Ubuntu 24.04 и новее AppImage с Electron не запускается из-за ограничений AppArmor — там ставьте `.deb`.

## Первый запуск

1. Выберите папку, где будут лежать конспекты. Это обычные `.md`-файлы, их можно открыть в любом редакторе.
2. Откройте настройки (`Ctrl+,`, на macOS `⌘,`) и вставьте свой ключ Claude API. Ключ берут на [console.anthropic.com](https://console.anthropic.com/) → API Keys, на счёте нужен положительный баланс. Ключ хранится зашифрованным только на вашем компьютере.
3. В «Тратах» нажмите карандаш и впишите, сколько сейчас денег на счёте Anthropic. Дальше приложение само вычитает стоимость каждого запроса.

## Обновления

Приложение само проверяет новые версии — при запуске и раз в 4 часа. Ничего настраивать не нужно.

- **Windows и Linux:** новая версия скачивается в фоне, в шапке появляется кнопка **«Перезапустить»**. Если её не нажать, обновление поставится при следующем закрытии. Для `.deb` система спросит пароль.
- **macOS:** в шапке появляется **«Вышла версия … — Скачать»**. Кнопка открывает страницу версии: скачайте `.dmg` и замените приложение в «Программах» (macOS не даёт неподписанным приложениям обновляться самим).

Конспекты, чаты и настройки при обновлении сохраняются. Проверить вручную и открыть список всех версий — **Настройки → Обновления**.
